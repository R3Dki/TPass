# TPass
TPass Password Manager

A 100% Self-Hostable Password Manager made with Java, Spring Boot and PostGres.
I plan to implement a system that stores sensitive data(such as passwords or credit card information)<br>in a way that guarantees security to the end user which cannot be bypassed even by the service host.<br>This method will also make it so if the database is somehow dumped it's contents are useless due to not knowing user passwords.

This project is still WIP.
